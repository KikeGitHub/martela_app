# Directorio de Reportes GAP y Oráculo E2E (`/docs/gap-analysis/`)

Este directorio almacena los entregables de verificación del ciclo SDOP:
1. **`gap-report-[NOMBRE_MODULO].md`**: Generado en **Fase 1** por la skill `demo-gap-analysis` en modo estricto SOLO LECTURA (`READ-ONLY`).
2. **`e2e-report-[NOMBRE_MODULO].md`**: Generado en **Fase 4** tras ejecutar el Oráculo Playwright (flujos de negocio, monitoreo de consola sin errores HTTP 500 y regresión visual `toHaveScreenshot`). Requerido para el **Punto de Control Humano #2**.
